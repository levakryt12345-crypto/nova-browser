Возможности

Всё необходимое — и ничего лишнего.

Реальные вкладки

Каждая вкладка — полноценный процесс рендеринга. Быстрое переключение (Ctrl+1…9), закрытие средней кнопкой мыши, перетаскивание.

Закладки и история

Стар звезда — и страница в закладках. История с поиском и очисткой. Всё хранится локально, никуда не отправляется.

Загрузки

Пауза, отмена, открытие папки — из панели загрузок (Ctrl+J). Автоматическое переименование при совпадении имён.

Темы

Тёмная, светлая и системная. Мягкие приглушённые цвета, режим для глаз. Переключается в настройках (Ctrl+,).

Своя страница настроек

Введите в адресной строке nova://settings — откроется встроенная страница настроек браузера: стартовая страница, поисковик, тема и список сайтов с разрешениями камеры/микрофона (управление и сброс).

Приватность

Никакой телеметрии. Никаких аккаунтов. Камера и микрофон — только после явного подтверждения, решения запоминаются и редактируются на странице настроек.

Безопасность

Валидация SSL, изоляция сайтов (sandbox), белый список IPC-каналов, строгая CSP. Полный аудит — в разделе ниже.

Установка на ПК (Windows 10/11)

Два способа: портативная версия (рекомендуется) или сборка из исходников.

1

Скачайте Nova Browser

Нажмите «Скачать для Windows» — загрузится файл NovaBrowser-1.0.0-portable.exe (≈ 93 МБ). Также он доступен в разделе Releases на GitHub.

2

Запустите

Двойной клик по exe — браузер открывается сразу. Ничего устанавливать не нужно: приложение работает «на лету» и не требует прав администратора.

3

Закрепите ярлык

Перетащите exe на рабочий стол или в панель задач для быстрого доступа. Данные (закладки, история, настройки) хранятся в %APPDATA%\Nova Browser и сохраняются между запусками.

Быстрый запуск: портативный exe распаковывается при каждом старте (≈10 сек). Для мгновенного запуска распакуйте его один раз (например, 7-Zip) в папку Nova Browser\ и запускайте Nova Browser.exe из неё — старт занимает меньше секунды.
Требования: Windows 10 (1809+) или Windows 11, 64-бит (x64), 1 ГБ ОЗУ свободно, 300 МБ на диске. Интернет нужен только для просмотра сайтов — сам браузер работает офлайн.

Установка на телефон

Отдельная мобильная версия Nova Mobile — скачивается и устанавливается как приложение.

Android · iOS · скачивается

Nova Mobile — отдельная версия

Лёгкий мобильный браузер: адресная строка, быстрые переходы, офлайн-режим. Скачивается одним файлом и устанавливается на главный экран как приложение.

⬇ Скачать Nova Mobile (8 КБ)
  1. Нажмите «Скачать Nova Mobile» — на телефон загрузится файл NovaMobile-1.0.0.zip.
  2. Распакуйте архив и откройте index.html в Chrome (Android) или Safari (iPhone).
  3. Нажмите «Установить» в плашке — или в меню браузера «Добавить на главный экран».
  4. Иконка Nova появится на главном экране — приложение запускается как нативное.
Онлайн-версия: Nova Mobile в браузере — открывается сразу, без скачивания. Сайты, запрещающие встроенный просмотр (Google, YouTube), Nova Mobile откроет отдельной вкладкой.
APK для Android (один файл, без распаковки) соберётся автоматически на GitHub Actions при публикации проекта — следите за разделом Releases.

Полный Nova Browser через Winlator

Хотите на телефоне именно полную версию браузера с вкладками и закладками? Winlator запускает Windows-приложения на Android.

  1. Установите Winlator из официального источника.
  2. Скопируйте NovaBrowser-1.0.0-portable.exe в память телефона.
  3. В Winlator создайте пресет (4+ ГБ ОЗУ, режим совместимости Windows 7).
  4. Запустите exe внутри Winlator — полноценный браузер на телефоне.
Эмуляция требует мощного телефона: Snapdragon 700-й серии и выше, 6+ ГБ ОЗУ.
iOS: Nova Mobile устанавливается на iPhone через Safari — «Поделиться» → «На главный экран». Полная версия браузера — через удалённый доступ к ПК (AnyDesk/Parsec).

Сборка из исходников

Вам понадобятся Node.js 20+ и npm. Полный процесс — около 5 минут.

git clone https://github.com/levakryt12345-crypto/nova-browser.git
cd nova-browser
npm install

# Запуск в режиме разработчика
npm start

# Сборка портативного exe (build/NovaBrowser-1.0.0-portable.exe)
npm run dist

# Автопроверка сборки (открывает страницу и делает скриншот)
npm run verify
Структура проекта: src/main — главный процесс (окна, вкладки, IPC), src/preload — безопасный мост, src/renderer — интерфейс (HTML/CSS/JS), scripts — генератор иконки, assets — иконки.

Безопасность

Результаты аудита перед публикацией. Все уязвимости закрыты.

✅ Что проверено

  • contextIsolation: true — сайты изолированы от главного процесса
  • nodeIntegration: false — сайты не имеют доступа к системе
  • sandbox: true — песочница во всех окнах
  • SSL-сертификаты проверяются (нет ignore-certificate-errors)
  • Камера и микрофон — только с вашего согласия: диалог «Разрешить / Отклонить» с запоминанием решения для сайта
  • Геолокация, уведомления и прочие разрешения — заблокированы
  • Белый список IPC-каналов в preload
  • Запрещены file:/data:/blob: из адресной строки
  • UI-окна не могут быть уведены на сторонние страницы
  • npm audit: 0 уязвимостей (Electron 43.4.1)

📦 Зависимости

  • electron 43.4.1 — актуальная стабильная версия
  • electron-builder 26.15.3 — сборка exe
  • Рантайм-зависимостей ноль — поверхность атаки минимальна
DevTools в собранной версии скрыты и включаются только флагом --nova-devtools для разработчиков.

FAQ

Nova Browser бесплатный?

Да, полностью. Проект с открытым исходным кодом (лицензия MIT).

Куда сохраняются закладки и история?

Локально, в %APPDATA%\Nova Browser (settings.json, bookmarks.json, history.json). Ничего не отправляется на серверы.

Почему Windows SmartScreen предупреждает при запуске?

Приложение пока не подписано цифровым сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае». Подпись кода появится в следующем релизе.

Будет ли мобильная версия?

Уже есть: Nova Mobile — отдельная мобильная версия для Android и iOS, скачивается и устанавливается на главный экран как приложение. Нативный APK для Android собирается автоматически на GitHub Actions. Полную версию можно запустить на Android через Winlator.

Как сообщить об ошибке или предложить фичу?

Откройте issue в репозитории GitHub — с описанием шагов воспроизведения, версией Windows и скриншотом, если можно.
